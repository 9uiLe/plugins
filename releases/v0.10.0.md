# Release Notes — v0.10.0

リリース日: 2026-10-22

## ハイライト

- **配布内容の整理**: `architecture-explainer` プラグインと、`model-strategy` の `model-effort-guide` Skill を削除しました。
- **model-strategy 0.6.0**: Agent・hook・statusline・参照資料を継続提供し、scope-guard のディレクトリ境界の誤判定を修正しました。
- **speakerdeck-knowledge 0.1.2**: SpeakerDeck の画像のみのページで本文が欠けていても、ページ順と画像の対応を保って取得できるようになりました。

### Fixed

- **speakerdeck-knowledge** (v0.1.2): SpeakerDeck が本文なしと明示した画像のみのページを、構造化データの `hasPart` から欠けていても取得できるよう修正。本文欠損とページ順・画像 URL の対応を保ち、欠損の根拠がない不完全なデータは引き続き拒否する。
- **model-strategy** (v0.6.0): scope-guard の `**/` を 0 階層以上のディレクトリに一致させるよう修正。`src/**/allowed.ts` が `src/notallowed.ts` まで許可していた誤判定を防ぎ、相対・絶対パスの両方で凍結範囲外の編集を警告する。

### Removed

- **architecture-explainer**: プラグインを削除。Claude Code / Codex の両 marketplace から登録を外し、CI と `scripts/verify.sh` から Bun の必須要件を外した。未リリースだった表示・Explanation Model・Presentation IR の変更も提供しない。
- **model-strategy** (v0.6.0、破壊的変更): Skill `model-effort-guide` を削除。Agent 定義（`haiku-scout` / `sonnet-implementer` / `judge` / `judge-fable`）、hook、statusline スクリプト、参照資料は引き続き提供する。

## Compatibility / Migration

- **破壊的変更**: `architecture-explainer` と `model-effort-guide` は、この版の配布対象に含まれません。これらを呼び出す作業指示・自動化は更新してください。このリリースに代替の Skill は含まれません。
- 既存の `architecture-explainer` 生成済み HTML は、standalone 文書として引き続き閲覧できます。旧 renderer が必要な場合は、`v0.9.0` タグの配布内容を参照してください。
- `model-strategy` の Agent・hook・statusline・参照資料は引き続き利用できます。scope-guard は従来見逃していた範囲外のパスを警告するため、警告が増えた場合は凍結範囲の指定を確認してください。
- `speakerdeck-knowledge` の入力と成果物の形式は変更していません。`engineering-principles` は v0.3.0 のままです。
