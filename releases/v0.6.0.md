# Release Notes — v0.6.0

リリース日: 2026-09-08

## ハイライト

- **model-strategy v0.4.0**: 総コンテキスト量・turn 数を抑える軽量な運用を既定に変更。詳細なルーティング監査や judge は明示 opt-in にし、委譲の起動・統合コストも判断に含めます。
- **配布プラグインの整理**: 未使用の4プラグイン・7スキルを削除し、`quality-architect` と `model-strategy` の2プラグイン構成に整理しました。
- **設計指針の整備**: 常駐指示、必要時に読む reference、委譲、hook のコンテキスト効率に関する共通指針を追加しました。

## Compatibility / Migration

- **破壊的変更があります**。`agent-ops`、`compact-plus`、`second-opinion`、`ios-build-optimization` は今回の配布対象から削除しました。
- 削除対象スキルは `agent-handoff`、`first-touch-review`、`crystallize`、`compact-plus`、`second-opinion`、`decision-council`、`ios-build-optimization` です。これらを呼び出す指示書・自動化・手動設定は、更新前に見直してください。従来の配布内容が必要な場合は v0.5.0 を参照してください。
- model-strategy は、モデル選択・利用量・委譲方針を明示的に相談する場面で起動します。従来の詳細な割当マニフェスト、完了監査、judge が必要な場合は、監査可能なルーティングや conductor mode を明示的に依頼してください。既存の opt-in hook 設定も用途に合わせて確認してください。
- quality-architect のプラグイン版は変更ありません。
