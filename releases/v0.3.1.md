# Release Notes — v0.3.1

リリース日: 2026-07-07

## ハイライト

- **新プラグイン compact-plus を収録**（v0.1.0）: Claude Code の `/compact` 前後でセッション状態を保存・復元する。[u-ichi/compact-plus](https://github.com/u-ichi/compact-plus) (MIT License) の移植。
- **圧縮前後を hook で自動化**: PreCompact で transcript をバックアップし LLM で 10 見出しの state file を生成、PostCompact/次プロンプトで復旧誘導を `additionalContext` に注入。閾値超過時には `/compact` 実行を促すリマインダーも出す。
- **移植にあたり自己完結化**: upstream が前提としていた作者 dotfiles 依存（session id 取得・warn マーカー生成）を解消するため、`scripts/get-session-id.sh` と `scripts/compact-warn-statusline.sh` を同梱した。

### Added

- プラグイン **compact-plus** (v0.1.0) を収録 — Claude Code の `/compact` 前後でセッション状態を保存・復元するプラグイン。transcript backup、LLM 生成の 10 見出し state file、閾値超過時の `/compact` 推奨通知、圧縮後の復旧誘導を hook で提供。[u-ichi/compact-plus](https://github.com/u-ichi/compact-plus) (MIT License) の移植で、session id 取得スクリプトと warn 通知用 statusline スクリプトを同梱して自己完結化した。

### Fixed

- ルート README の収録プラグイン表に、v0.3.0 で収録済みの **agent-ops** の行を追加 (記載漏れの修正)。

## Compatibility / Migration

- 破壊的変更なし。既存プラグイン（tech-docs / quality-architect / model-strategy / agent-ops）には変更ありません。
- `compact-plus` は新規追加のため、利用には `/plugin install compact-plus@9uile-plugins` でのインストールが必要です。
- state 生成のバックエンドは既定で `claude -p --model claude-sonnet-5`（フォールバックに `codex exec`）を使います。コストを抑えたい場合は `COMPACT_PLUS_PRIMARY_BACKEND` を Haiku 等に差し替えられます（詳細は `plugins/compact-plus/README.md`）。
- warn 通知リマインダーを使う場合は、同梱の `scripts/compact-warn-statusline.sh` を `settings.json` の `statusLine` に絶対パスで配線する必要があります（`${CLAUDE_PLUGIN_ROOT}` は statusLine では展開されません）。
