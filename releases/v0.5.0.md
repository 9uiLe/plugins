# Release Notes — v0.5.0

リリース日: 2026-08-17

## ハイライト

- **model-strategy の操作ルーティング (v0.2.0, PR #91)**: 「タスク分類 (モデルの自然言語裁量)」を、観測可能な述語のみで決まる先勝ちルーティング P0/R0〜R4 に置換。ルール正本は `scripts/route-policy.mjs` (判定・監査・CLI) で、委譲マニフェストにより「どのモデルに何を委譲したか」がユーザーに見える。
- **conductor mode (v0.3.0, PR #92)**: `MODEL_STRATEGY_MODE=conductor` の opt-in で Sonnet メイン運用に対応。R4 を R4-ctx / R4a (judge 召喚) / R4b (セッション昇格提案) に機械分割し、上方委譲の沈黙故障を「昇格 = 既定方向」+ 終端 judge ゲート + 監査 findings で防ぐ。高性能モデル (Opus/Fable) の消費がセッション長ではなく判断の回数に比例する。
- 設計は両バージョンとも orchestration (Orca) 経由の 2 アドバイザー諮問 (Codex gpt-5.6-sol / Claude Fable 5、各 2 ラウンド) で収束。機械検査の証明範囲 (well-formed and traceable まで) と既知の限界 (scope-guard の Bash 迂回、監査の自己申告依存) を `references/08-conductor-mode.md` に明文化している。

### Added

- **model-strategy / model-effort-guide** (v0.1.1 → v0.3.0): 先勝ち操作ルーティング P0/R0〜R4 (正本 `scripts/route-policy.mjs`、references/02 とのドリフトは同期テストで検知)、委譲マニフェスト表示規定、opt-in route-warn hook (`agent_id` によるメイン/サブ判別、状態は `CLAUDE_PLUGIN_DATA` のみ)、`subagentStatusLine` 用委譲可視化スクリプト。
- **conductor mode**: R4 の 3 分割 (`deriveR4Subtype`)、`judge` (Opus) / `judge-fable` (静的別定義) エージェント — Read/Grep/Glob で一次ソースを自分で読み、呼び出し不能時は fail-closed。受け入れの独立再ルーティング、R3 の contractRef / verificationRef / `verify-evidence` (引用実在検査)、scope-guard hook (凍結範囲 + baseline ライフサイクル + 不発検出 `MISSING_BASELINE`)、失敗シグナル分類、監査 findings (`CONDUCTOR_EXECUTED_R4` / `MODE_MODEL_MISMATCH` 等)。

### Changed

- **model-strategy**: `haiku-scout` (R1/R2 語彙)・`sonnet-implementer` (R3 語彙 + 構造化結果ステータス) を更新。references 02/03/04/06/07 をルール ID 体系に整合し `08-conductor-mode.md` を新設。CI に model-strategy テスト (60 件) を追加。

## Compatibility / Migration

- 破壊的変更なし。hooks (route-warn / scope-guard) と conductor mode はいずれも**既定で不活性の opt-in** (`MODEL_STRATEGY_ROUTE_WARN=1` / `MODEL_STRATEGY_MODE=conductor`)。env 未設定時のルーティング判定は v0.2.0 実装が v0.1.1 時点の推奨と互換の担当割り当てを返し、既存テスト 17 ケースは無修正で PASS。
- `model-effort-guide` スキルの手順書はタスク分類から操作ルーティングへ全面改稿されたが、スキルの呼び出し方 (トリガー) に変更はない。
- 委譲可視化 (`subagentStatusLine`) を使う場合は settings.json への手動配線が必要 (references/06 §7。プラグイン同梱 settings.json は `${CLAUDE_PLUGIN_ROOT}` 展開が公式未確認のため見送り)。
