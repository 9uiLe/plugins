# Release Notes — v0.7.2

リリース日: 2026-09-14

## ハイライト

- **speakerdeck-knowledge 0.1.1**: 本文から確認対象を選び、縮小画像・必要領域の切り出し・最大6ページの俯瞰画像で段階的に読解する手順を提供します。
- 取得済み画像と生成済み画像を再利用し、確認メモで再読を抑制。HTML の画像埋め込みはローカルで処理し、画像データをセッションへ出力しません。
- 画像取得・加工の回帰テストと利用手順を補完し、不要になった旧ドキュメントと表示用アセットを整理しました。

### Fixed

- **speakerdeck-knowledge** (v0.1.1): 本文を先に読み、必要ページの縮小画像・部分拡大・最大6ページの俯瞰画像だけを段階的に閲覧する手順へ変更。確認メモによる再読抑制、取得済み画像の再利用、HTML の base64 をセッションへ出力しない処理を明記し、画像生成補助と回帰テストを追加。

### Removed

- 不要になった旧 ADR と表示用アセット、旧ハンドオフ指示書を削除し、現行ドキュメントの参照を整理。

## Compatibility / Migration

- 既存のスキル名・成果物の形式・保存先に破壊的変更はありません。speakerdeck-knowledge を 0.1.1 へ更新して利用してください。
- 閲覧用画像の生成補助には Pillow が必要です。利用する Python 環境で `python3 -m pip install Pillow` を実行してください。本文取得だけなら Pillow は不要です。
- 画像の枚数・寸法・再読を抑える変更です。実際の token 使用量はモデルや閲覧ツールに依存し、固定の削減率は保証しません。
- 旧 ADR・表示用アセット・旧ハンドオフ指示書を削除したため、それらへの直接リンクは利用できなくなります。
- quality-architect 0.1.5、model-strategy 0.4.1 は継続提供します。
