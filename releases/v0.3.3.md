# Release Notes — v0.3.3

リリース日: 2026-07-10

> このファイルは雛形です。`## ハイライト` を手で書き加え、必要に応じて節の説明を膨らませてください。

## ハイライト

- **second-opinion**: アドバイザーの Codex バックエンドが上位モデル `gpt-5.6-sol` を明示的にピン留めするよう修正。app-server の既定に委ねて意図せず下位モデルへ落ちる問題を解消し、モデルが失敗した場合は codex 既定へフォールバックしてレビュー自体は落とさない。実効モデルは結果ヘッダに表示される。


### Fixed

- **second-opinion**: advisor の Codex バックエンドがモデルをピン留めせず app-server の既定に委ねていたため、意図した上位モデル (`gpt-5.6-sol`) が使われないことがあった。`runCodex` が `--model` を**常に明示的に**渡すよう変更（既定 `CODEX_MODEL = gpt-5.6-sol`、環境変数 `SECOND_OPINION_CODEX_MODEL` で上書き可）。ピン留めモデルが失敗した場合は `--model` なしで一度だけ再試行して codex 既定へ退避し、レビュー自体は落とさない。結果ヘッダに実効モデルを表示するようにした。

## Compatibility / Migration

- 破壊的変更なし。Codex モデルを変更したい場合は `scripts/second-opinion.mjs` の `CODEX_MODEL` 定数、または環境変数 `SECOND_OPINION_CODEX_MODEL` を設定する。
