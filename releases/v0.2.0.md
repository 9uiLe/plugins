# Release Notes — v0.2.0

リリース日: 2026-07-04

## ハイライト

- **codex-handoff を状態駆動の委譲フローへ拡張**（agent-ops v0.1.0 → v0.2.0）: 指示書の穴を着手前に露呈させるゲート、委譲ごとの計測台帳、Fable 非依存化プログラム（DR 目標）、監督役の自動進行プロトコルを追加。
- **着手前ゲート（M0）**: 実行モデルのフレッシュセッションに調査・作戦フェーズを実施させ、未確定事項を「確認が必要 / 仮定して進められる」に二分して着手前に回収する。高リスク時は 2 モデル独立のアンサンブル批評を追加。
- **Fable 非依存化プログラム**: Fable が利用できなくなっても自分の指示 + Opus/Codex で同等の委譲品質を維持することを目標に、ベースライン記録・批評採掘・Fable-off 訓練・フェーズ移行判定を定義。
- **運用プロトコル**: フェーズや Fable-off 周期の記憶を台帳先頭の状態ヘッダに移し、監督役セッションが発火直後に運用モードを宣言して各ステップの次の行動を提示する。ユーザーが覚えるのはトリガーフレーズ 1 つ。

### Added

- **agent-ops** `codex-handoff` に着手前ゲート・振り返り台帳・Fable 非依存化プログラムを追加 — 指示書テンプレートへ「非目標」「未確定事項と仮定」「事前調査」セクションと M0（調査・作戦フェーズ）を追加し、未確定事項を二分類で着手前に回収するゲート（references/03）、委譲ごとの振り返り 4 行 + 4 指標の台帳（references/04）、Fable 非依存化プログラム（references/05）を新設。監査チェックリストに「指示書起因」タグを追加。(#38)
- **agent-ops** 運用プロトコルを追加 — 手順の記憶を台帳の状態ヘッダへ移し、監督役セッションが自動進行する（references/06）。(#39)

### Changed

- **agent-ops** プラグイン版を v0.1.0 → v0.2.0 に更新。

## Compatibility / Migration

- 破壊的変更なし。既存プラグイン（tech-docs / quality-architect / model-strategy）には変更ありません。
- `codex-handoff` のフローがステップ 0〜7 の 8 段階になります。既存の指示書テンプレート利用分には「非目標」「未確定事項と仮定」「事前調査」「M0」の追記を推奨します。
- 委譲先プロジェクトの台帳 `docs/handoff-ledger.md` は初回発火時に監督役が状態ヘッダ付きで自動作成します。事前準備は不要です。
