# Release Notes — v0.7.0

リリース日: 2026-09-08

## ハイライト

- **speakerdeck-knowledge v0.1.0** を追加。SpeakerDeck の公開スライドを、AI への実装依頼に使う Markdown と、初めて資料を読む人向けの HTML にまとめます。
- 文字起こしのないスライドは画像から読解し、出典・適用条件・検証方法を整理します。原資料の説明、画像からの観察、独自の応用提案を区別します。
- README と貢献手順、Issue / PR テンプレートを現行の配布内容に合わせて更新しました。

## 新しいプラグインの使い方

Claude Code / Codex の marketplace から `speakerdeck-knowledge` を導入し、次のように依頼します。

```text
$speakerdeck-knowledge
URL: https://speakerdeck.com/kgsi/pdeconf2026-design-harness
出力: Markdown と HTML
適用先: 既存プロダクトの画面レビュー
```

保存先の既定値は作業ディレクトリの `ai-knowledge/<資料の URL 識別子>/` です。`knowledge.md` に判断基準・作業手順・AI 作業指示を、`guide.html` に目次・凡例・原図と読み解きをまとめます。形式や保存先を明示することもできます。

取得スクリプトは本文・画像・書誌情報を保存し、画像のみのページ、ページ順序と欠損本文、画像取得の部分失敗を扱います。ローカル検証用の `examples/` は配布対象に含みません。

## Compatibility / Migration

- 既存プラグインの破壊的変更はありません。`quality-architect` は v0.1.5、`model-strategy` は v0.4.0 を維持します。
- 新プラグインには、本文と画像を理解できる AI エージェント、公開 URL の閲覧手段、表示確認用のブラウザが必要です。取得補助には Python 3 と curl を使います。
- 資料の生成は、対象プロジェクトの実装変更や外部への公開・送信を含みません。
