# Release Notes — v0.1.8

リリース日: 2026-07-03

## ハイライト

- **新プラグイン agent-ops を収録**（v0.1.0）: Fable 導入後 7 プロジェクト・21 セッションの実利用履歴から「再利用可能 / 高コスパ / 繰り返し」の 3 基準で抽出したエージェント運用規律を 3 Skill 化。
- **`codex-handoff`**: 指示書（正典・禁止事項・停止点・受け入れ条件）を固定してから外部エージェントへ委譲し、監査チェックリスト 7 項目（自己報告の独立検証・否定的証明の対照群など）で証拠ベースに受け入れる。
- **`first-touch-review` / `crystallize`**: 固定 6 観点ルーブリックの初見ユーザー評価を実機で反復するレビューループと、セッション知見を lint / script / skill / ADR へ資産化するルーティングを提供。


### Added

- プラグイン **agent-ops** (v0.1.0) を収録 — Fable 実行履歴から抽出したエージェント運用規律プラグイン。指示書駆動の外部エージェント委譲と懐疑的監査を行う Skill `codex-handoff`、固定ルーブリックの初見ユーザー評価を実機で反復する Skill `first-touch-review`、セッション知見を lint / script / skill / ADR に資産化する Skill `crystallize`、リファレンス 8 編を提供。

## Compatibility / Migration

- 破壊的変更なし。既存プラグイン（tech-docs / quality-architect / model-strategy）には変更ありません。
- `agent-ops` は新規追加のため、利用には `/plugin install agent-ops@9uile-plugins` でのインストールが必要です。
- `codex-handoff` の実行経路リファレンスは `headroom` CLI（`headroom wrap codex`）の利用を前提とします。未導入環境ではスキルの指示書・監査部分のみ利用できます。
