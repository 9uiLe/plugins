02 / Inline & Callouts

Callout / 注釈ボックス

強調すべき情報を色とアイコンで分類します。本文中で .callout を使ってください。

i

Note

中立的な補足情報や前提条件を示すときに使います。背景はニュートラル。

i

Info

関連リンクや参考情報、補足の説明に。インディゴではなく info ブルー を使います。

★

Tip

推奨パターンやベストプラクティスを伝えるときに。ブランドアクセントカラーで強調されます。

!

Warning

注意が必要なこと、トレードオフ、既知の制限事項を示します。

!

Danger / Breaking

破壊的変更や絶対に避けるべきパターンを警告します。

✓

Decision

ADR 内で「採用した決定」を強調するために使うことが多いです。

インライン要素

本文中で inline code を強調できます。ショートカットは ⌘ + K。ハイライト を入れたい場合は <mark> を使ってください。

バッジ / ステータス
