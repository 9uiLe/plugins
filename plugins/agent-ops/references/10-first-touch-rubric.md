# 初見ユーザー評価ルーブリック

次のプロンプトをコピーして使う。

```markdown
あなたはこのアプリを初めて触るユーザーです。実際に操作して以下の観点で評価してください。

出力は観点ごとに、重大度 (致命/重大/軽微)、再現手順、期待挙動、実際の挙動を書いてください。
```

## 固定ルーブリック

1. **パフォーマンス**
   起動時間、フレーム落ち、発熱、CPU 使用率を見る。操作のたびに待ちが発生しないか、初回起動と再起動で差がないかを確認する。

2. **UI と仕様の整合性**
   表示と実挙動が一致しているかを見る。状態遷移、戻る操作、保存・取消、エラー表示が仕様どおりかを確認する。

3. **UX と収益のバランス**
   広告・課金導線が体験を壊していないかを見る。導線の事前予告、閉じ方、誤タップ誘発の有無を確認する。

4. **面白さ・継続動機**
   コアループが成立しているかを見る。次に何をしたいかが自然に生まれるか、進捗や報酬が理解できるかを確認する。

5. **フィードバック**
   操作への視覚・触覚・聴覚応答が即時に返るかを見る。成功、失敗、待機中、完了の状態が区別できるかを確認する。

6. **デザイン**
   階層、余白、一貫性を見る。重要な情報が埋もれていないか、同じ意味の UI が同じ見た目で表現されているかを確認する。

## 種別による差し替え

ゲーム系では観点 4 を強め、コアループ・報酬・リトライ動機を詳しく見る。ツール系では観点 3 と 4 を、業務効率・信頼性・再利用頻度に読み替える。
