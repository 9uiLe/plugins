# Claude Code 実行経路

外部エージェントとして Claude Code を使う場合は、必ずトークン計測プロキシ経由で起動する。
これ以外の起動フラグは創作しない。

## 起動形態

対話:

```bash
headroom wrap claude
```

非対話:

```bash
headroom wrap claude -- -p --permission-mode acceptEdits "<プロンプト>"
```

非対話実行では、対象リポジトリを cwd にして実行する。
プロンプトには指示書ファイルの絶対パスを渡し、「最初に全文読んでから作業する」ことを明記する。

## 長時間実行

長時間の実行はバックグラウンドで走らせ、完了後にログを確認する。

並行作業が必要な場合は worktree で分離してから委譲する。

書き込み先が workspace 外なら失敗するため、指示書で書き込み先を明記する。

## 境界

モデル・effort・価格の判断はここには書かない。インストールされていれば `model-strategy` を参照する。
