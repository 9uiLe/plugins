# PC 向け共有 HTML の設計

読者は資料を初めて読むチームメンバー。目的、使う場面、用語、根拠を資料内で説明し、判断から実行へ進める構成にする。Markdown の知識 ID、結論、条件、作業、検証、限界を保持する。

## ページ構造

| 領域 | 内容と役割 |
| --- | --- |
| ヘッダー | タイトルと説明、使う場面と用語、出典と公開情報 |
| 左サイドバー | 本文順の目次と「原資料・画像観察・応用提案」の凡例 |
| 全体像 | 読者が取り組む問題と、知識を使う順序や関係 |
| 知識セクション | 判断基準、使う場面、根拠、実務への適用、検証、限界 |
| 実践例 | 具体的な入力条件から調査・判断・作業・検証までの手順 |
| AI への作業指示 | 必要な入力、受入条件、停止・相談条件、コピー用の指示全文 |
| 出典と読解範囲 | 書誌情報、確認ページ、画像精読範囲、未確認・未実証の事項 |

目次には見出し「目次」を付け、本文の主要セクションを順序どおりに並べる。項目名は本文見出しに対応させる。長い資料では番号を付ける。目次と凡例は左側に追従表示し、高さが不足する場合は目次内をスクロール可能にする。凡例は参照できる位置に保つ。

PC 専用のレイアウトとし、サイドバー幅360pxを起点に本文幅とのバランスを調整する。スマートフォン用の切り替えは用意しない。印刷では本文を一列にし、サイドバーを隠す。

## 情報の階層と余白

余白は情報の関係を示す。関連する項目を狭い間隔でまとめ、異なる役割のまとまりの間を広く取る。ヘッダーは「タイトルと説明」「使う場面と用語」「出典名と公開情報」の三つを単位にする。`assets/guide.css` は、グループ間28px、見出し群内12px、メタデータ行間8px、出典名と公開情報の間2pxを使う。数値は改行と情報量を見て調整する。

各まとまりの間隔は親の `gap` などで管理し、子要素の既定 margin が加算されないようにする。見出し階層とラベル列の整列を共通化する。背景色は適用条件、観察の補足、適用の限界など、内容の役割を表す箇所に使う。

**Divider は目次に記載する本文セクション同士の境界に限って使用できる。** 必須ではなく、余白で十分なら省く。使用する場合は目次のリンク対象に明示的なクラスを付け、その隣接境界だけを指定する。セクション内、表の行、手順、メタデータ、目次の項目間、目次と凡例の間には入れない。`hr`・疑似要素・背景画像などで描く区切り線も同じ規則に従う。操作部品の輪郭、フォーカス表示、原図内の線はそれぞれの機能に従う。

## 根拠を伝える表現

| 伝えるもの | 表現 | 添える情報 |
| --- | --- | --- |
| 実画面の配置・強弱・視線の順序 | 必要な原図 | 画像内で特定できる観察箇所と、その意味 |
| 原資料の階層・矢印・空間的関係 | 原図 | 読み順、関係の意味、解釈の限界 |
| 文言や条件の使い分け | 比較表 | 適用条件、欠点、避ける状況 |
| 作業順序 | 番号付き手順 | 入力、作業、完了条件、失敗時の戻り先 |
| 応用で扱う複雑な分岐や関係 | 必要に応じた図 | 応用・推論の表示と、同等のテキスト説明 |

原図のある節は「原図 → 観察箇所 → 再利用できる原則 → 応用」の順に読めるようにする。観察箇所は「右下のボタンの強弱」のように画像内を指せる表現にする。図の形や配置を理解する根拠には原図を使う。再作図は関係をより明確に伝えられる場合に選び、原資料との対応を照合する。架空の UI は独自の適用例として示す。

原図には著者、ページ、出典リンク、alt、キャプションを付ける。加工した場合は変更箇所を示す。画像内の文字が縮小で読みにくくなる場合は、原寸表示や拡大表示を用意する。図と説明は近接させ、説明する関係を画像上で見つけられることを確認する。

## 知識セクションと作業指示

知識 ID、判断基準を表す見出し、使う場面を入口に置く。根拠と観察に続けて、応用の理由と行動を記す。作業・具体例・検証・適用の限界は、ラベルと本文を対応させた行などで区別する。具体例は内容に必要な場合に記載する。

実践例には対象者と入力条件を明記し、実際の作業順に番号を付ける。AI への作業指示は、入力、受入条件、停止・相談条件を本文で常時表示する。指示全文は開閉領域に置ける。Markdown と照合し、具体的な条件や例外を保持する。

## 配布と操作

`assets/guide.css` を土台として、資料に使う規則を HTML の `style` に埋め込む。単体共有では引用画像を data URI、必要な JavaScript をインラインで含める。画像が多くファイルサイズが問題になる場合は HTML と画像フォルダを一組で渡す。出典リンクを残し、表示に CDN・外部フォント・通信を必要としない構成にする。取得キャッシュやスライド全文は配布対象に含めない。

言語を示す `lang`、ページタイトル、viewport、適切な見出し階層、アンカーを設定する。色にはラベルを併用する。拡大や開閉はキーボードで操作でき、閉じた後は起点へフォーカスを戻す。JavaScript 無効時も知識と作業指示を閲覧できるようにする。

## 完了確認

- PC の幅と高さを変えてスクリーンショットを撮り、実際に見る。ヘッダーのまとまり、本文の読み順、図の可読性、見切れ、サイドバーの追従と内部スクロールを確認する。
- 目次の全リンク、拡大、開閉、キーボードのフォーカスを操作する。JavaScript 無効時の本文と指示全文、表示時の外部通信とスクリプト例外を確認する。
- 印刷では操作部品を隠し、開閉内容を表示し、図とキャプションの分断を避ける。
- Markdown の知識 ID と各項目、根拠ページ、AI 指示を照合する。未検証の環境や読解範囲を検証結果に記載する。
