## 取得と読解

リポジトリルートから実行する。

```bash
rtk proxy python3 plugins/speakerdeck-knowledge/skills/speakerdeck-knowledge/scripts/fetch_deck.py \
  'https://speakerdeck.com/kgsi/pdeconf2026-design-harness' \
  --out /tmp/design-harness-source --images all
```

33画像を取得し、画像取得失敗は0件。ページ数の根拠は対象資料の transcript ブロック。文字起こしはなく、サイトの欠損表示のみである。画像リンクと欠損本文を保持した33ページとして解析できることを保存済み HTML で確認した。著者は `og:author` から取得できる。公開日は公開ページで確認し、取得補助の空欄から推測していない。

全画像を俯瞰し、p.4・10・18・19・20・21・22・25・26・27・30 を原寸で精読した。共有資料には、四層モデル、検証、フィードバックの関係を説明する p.18・21・22 を未加工で引用した。

p.13〜16 の外部紹介記事、Atlas の実装コード、デモの操作、比較実験の再現は確認していない。小さな画面内テキストは全件精読していない。
