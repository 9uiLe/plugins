# Advisor transport completion

Treat transport status as evidence, not completion authority. Before synthesis, require one durable `worker_done` for every supervised dispatch. Match its task ID, dispatch ID, and sender to the live dispatch. Ignore stale or mismatched messages, but retain them as findings.

Apply the guard only to `SUPERVISED` transports; explicitly named direct CLI, host-native, and other fallbacks are `NOT_APPLICABLE` with no synthesis authorization, while unknown transport labels fail closed. Capture one snapshot containing the dispatch and messages; a collection record with finalization reason, finite fetch count, start/final timestamps, and cursor; and a matching `PERSISTED_MESSAGE_STORE` observation cursor. A valid completion requires finalized collection and dispatch status `completed`; exactly one matching `worker_done` with a persisted message ID and sequence; a non-empty result body or report content captured into council evidence; and no duplicate completion or failed dispatch. These fields validate adapter-supplied persisted-store observation evidence; they do not prove upstream durability or transaction atomicity.

Do not infer success from task completion, terminal idleness, or completion metadata alone. Before acting on a missing-message finding, re-read the inbox once to reduce snapshot-race false positives; this is a metadata refresh, not an advisor retry. If completion remains missing, do not retry beyond the preflight retry ceiling. Record the advisor as `OUTPUT_MISSING`, lower independence/confidence, and either stop or use an authorized capability fallback. Never summarize an advisor position that was not recovered.

When Node.js is available, validate a normalized snapshot with `scripts/completion-guard.mjs`. Map authenticated host fields into `dispatch.id`, `dispatch.taskId`, `dispatch.assigneeHandle`, `dispatch.status`, and message `id`, `sequence`, `type`, `fromHandle`, `body`, `reportContent`, and `payload`. The guard does not mutate runtime state, prove store atomicity, or repair the upstream lifecycle race.
