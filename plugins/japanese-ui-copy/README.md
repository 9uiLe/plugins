# Japanese UI Copy

HTML・アプリ・可視化の日本語UI文言を作成・見直しする Claude Code / Codex 用プラグインです。操作と状態が分かる表現にし、用語・意味・表示と支援技術向けの文言を揃えます。一般記事の校正には使いません。

## インストール

```text
/plugin marketplace add 9uiLe/plugins
/plugin install japanese-ui-copy@9uile-plugins
```

```bash
codex plugin marketplace add 9uiLe/plugins
codex plugin add japanese-ui-copy@9uile-plugins
```

## 依頼する

収録スキルは [japanese-ui-copy](skills/japanese-ui-copy/SKILL.md) です。対象画面やファイルに加え、用語集・仕様・文体の指定があれば添えて依頼します。指定がなければ、一般利用者向けの簡潔で中立的な文体を仮置きします。

| 用途 | 依頼例 |
| --- | --- |
| 作成 | 「japanese-ui-copy を使い、この設定画面の見出し・説明・ボタン文言を作成して」 |
| レビュー | 「このHTMLの日本語UI文言をレビューして。修正候補と理由を示して」 |
| 直接編集 | 「japanese-ui-copy を使い、この画面の日本語UI文言を修正して。動作と条件は維持して」 |

レビューではファイルを変更せず、対象と修正候補・理由を返します。直接編集では、表示文言とアクセシビリティ用文言を調べ、共有文字列への波及と差分を確認します。文言以外の実装変更が必要な場合は、明示的な実装依頼の範囲で扱い、それ以外は分けて提案します。

結果には変更点または修正候補と理由、確認した範囲・結果・未確認事項を含めます。実画面、アクセシブルな名前・説明の取得結果、実際の読み上げ機器は、それぞれ確認した範囲を区別します。

## 検証

実行用スクリプトや追加依存はありません。リポジトリの構成検査は [コントリビューションガイド](../../CONTRIBUTING.md#ローカルで検証する) の `bash scripts/verify.sh` を使います。

スキルの変更時は、実行者へ対象のスキルと生の資料・依頼を渡し、次のようなケースで実際の変更と報告を確認します。実画面の確認には対象UIを実行できる環境が必要です。

| ケース | 確認する挙動 |
| --- | --- |
| レビューのみの依頼 | ファイルを変更せず、箇所・候補・理由を返す |
| 確認画面へ進むボタン、条件・数値を含む説明、原因不明のエラー | 実行済みの表現や条件の読み替え、原因・復旧・保存状況の創作を避ける |
| 共有翻訳キー、補間変数、処理値を含むUI | 参照先を調べ、キー・補間・処理値を保ち、対象外の用途へ変更を広げない |
| 表示ラベルと読み上げ用文言が異なるUI、実画面が使えない環境 | 名前の取得元を確認し、表示との対応を揃え、未実施の確認を明記する |
